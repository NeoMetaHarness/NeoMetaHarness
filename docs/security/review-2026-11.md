## Reviewed and sound

- `/internal/memory/*`: the profile is validated by regex, the token is a per-profile 64-hex vault secret compared with `timingSafeEqual`, the body is capped at 64 KiB, and results are filtered to `global` plus the caller's own subject.
- `/internal/computers/action`: 256-bit capability tokens with a map lookup, revocation checked per action, a 16 KiB body cap and a zod-validated action.
- WS: tickets are single-use with a 15-second lifetime and are swept; the bearer subprotocol is echoed only after authentication.
- DSH env projection uses an allowlist and never spreads `process.env`. The Hermes `.env` owned block uses allowlisted keys, refuses symlinks and writes atomically.
- Skills git calls use `execFile` with `--` separators and validated names.
- P4-6 Hub install: only `preview.skill_md` is imported, any extra manifest file or path escape blocks install even with approval, the scan is regex only (no code runs; frontmatter is read with `yaml.parse`), approval and override are admin-only and written to `audit.jsonl` before state changes, and approval is bound to the content hash. Every new route has a policy entry, and each handler authorizes before doing any work.
- Tauri capabilities are `core:default` only; the window loads `WebviewUrl::App`; the token is not logged.

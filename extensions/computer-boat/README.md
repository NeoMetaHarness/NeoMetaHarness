# Boat computer provider

Enable `computer-boat` in Neo extensions, then configure its **Boat API base URL** and **Boat API key** in Settings. The key uses the kernel's `secret: true` settings property and is stored in the encrypted vault. The default URL is `https://boat.dev/api/v1`. A self-hosted API can use a different HTTPS URL, or HTTP on loopback for local development. The provider resolves these settings when provisioning each computer.

Call `computers.provision` with `providerId: 'computer-boat'` and optional `spec.type` (`small`, `default`, `large`, `xlarge`) and `spec.ttlSeconds`. To fork a running, Neo-managed computer within the same workspace, pass its Neo computer ID as `spec.forkOf`. Provision and fork use Boat's `Idempotency-Key` header. `computers.release` stops the sandbox and retains its newest disk snapshot. `computers.terminate` permanently deletes it. The owner-only `POST /x/computer-boat/snapshot` with `{ "id": "neo-..." }` creates a named saved snapshot.

Actions and captures travel through the shared ComputerRegistry, which handles per-bot capability tokens, human lease priority, kill-switch preemption, origin/key safety policy, and action audit. The provider uses Boat's remote command endpoint to run X11 `xdotool` input and ImageMagick's `import` screen capture inside the sandbox. The sandbox environment must provide `python3`, `xdotool`, `import` and a working X11 desktop. Captures reject invalid or truncated PNG data. `screen()` returns Boat's secret-bearing WebRTC desktop URL and should be shown only in an authenticated viewer.

API sources checked on 2026-11-20: `https://docs.boat.dev/api/v1`, `/api/reference/sandboxes/create-sandbox`, `/api/reference/sandboxes/fork-sandbox`, `/api/reference/sandboxes/stop-and-archive-sandbox`, `/api/reference/sandboxes/permanently-delete-sandbox-data`, `/api/reference/agent/execute-sandbox-command`, `/api/reference/agent/get-desktop-streaming-url`, `/api/reference/snapshots/get-latest-sandbox-snapshot`, `/api/reference/snapshots/save-saved-snapshot` (all under `https://docs.boat.dev`). Live cloud and PandaOS compatibility require operator validation. `pnpm test:p3-11` uses an isolated fake Boat HTTP server and makes no billable calls.
